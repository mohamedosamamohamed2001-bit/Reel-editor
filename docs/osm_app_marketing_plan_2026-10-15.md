## 2. Most marketable features (all verified)
1. Real coach behind the app: weekly check-in read by the coach, plan revised, chat with voice notes.
2. Workout with exercise demo videos + per-set logging (reps/kg) + rest timer.
3. Diet in grams with **swaps** that keep the plan working (9 alternatives for chicken breast alone).
4. Daily challenge → points → leaderboard → badges → real rewards (Dragon gear).
5. Visible consistency: streak calendar, consistency %, progress measurements + photos.

Differentiator: the site's own line, "Train with a coach, not an app." OSM pairs a one-coach method with gamified accountability.

## 3. Campaign concepts
A. **"COACH, NOT AN APP"** (complete experience, recommended)
B. **"EARN IT"** (daily challenge → points → badges → rewards)
C. **"SWAP IT, DON'T QUIT IT"** (nutrition flexibility + tracking)

Recommended: A as the umbrella campaign, with B and C as recurring formats under it (see chat summary / plan).
